# AI Smarter 3페이지 웹사이트 구축 계획

## 구현 범위
- 메인, 활용 효과, 요금제의 3개 페이지와 공통 상단 메뉴를 만듭니다.
- 모든 문의·무료 시작 버튼은 메인 페이지 하단의 문의 영역으로 자연스럽게 이동시킵니다.
- 메인에는 대시보드형 제품 화면, 문제/해결 비교, 3개 기능 탭, 리뷰 입력 데모, 3가지 문의 방식을 구성합니다.
- 활용 효과에는 성과 수치, 4단계 자동화 과정, 실제 매장 사례 슬라이드를 구성합니다.
- 요금제에는 월간/연간 전환, 3개 요금제, FAQ를 구성합니다.

## 문의 및 신청
- 이메일 무료 체험 신청은 안전하게 저장되도록 Lovable Cloud를 연결합니다.
- 상담 알림 수신 주소는 `ucpark01@gmail.com`으로 설정합니다. 이메일 발송용 도메인이 준비되지 않았다면 신청 내역 저장을 우선 완료합니다.
- 전달받은 구글폼 값이 이메일 주소이므로 구글폼 버튼은 “링크 준비 중” 상태로 표시합니다.
- 카카오톡 링크가 없으므로 오픈채팅 버튼도 “링크 준비 중” 상태로 표시합니다.

## 디자인
- 딥 인디고, 바이올렛, 코랄, 카카오 옐로우를 의미 기반 색상으로 정의합니다.
- 한글 가독성을 우선하며 제품 화면과 실제 사용 흐름이 첫 화면에서 바로 보이도록 구성합니다.
- 모바일 메뉴, 탭, 데모, 슬라이드, FAQ, 요금제 전환을 모두 실제 동작하도록 만듭니다.

## 기술 세부사항
- React 19, TanStack Start, Tailwind CSS v4, Lucide 아이콘을 사용합니다.
- 3개 콘텐츠 경로에 고유한 검색·공유 메타데이터를 추가합니다.
- 신청 저장, 오류 상태, 성공 안내를 구현하고 데스크톱/모바일 화면에서 확인합니다.
